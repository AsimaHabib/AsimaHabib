## About

I'm an AI/ML engineer and Python developer who builds intelligent, data-driven applications end to end, from model development to the APIs and interfaces that put them in front of users.

My work centres on **machine learning and deep learning**, **AI-powered applications and chatbots**, and **full-stack development** with REST APIs and backend services. I'm currently deepening my skills in **MLOps** through **Docker**, **Azure**, and **Apache Airflow**, so that the models I build are easier to deploy, schedule, and maintain.

I'm motivated by using technology to solve real-world problems, and I'm open to opportunities and collaborations in AI/ML and software development.
